🚀 3. Anleitung: Firmware auf den ESP32 flashen

                    Schritt 3
                

                

                    

                        
                        
                        

                            
🏠 Methode 1: Home Assistant ESPHome

                            
Der einfachste Weg, wenn du Home Assistant nutzt:

                            
    
                                
  1. Öffne das ESPHome Dashboard in Home Assistant.
    2. 
                                
  2. Klicke auf + New Device und wähle Open ESPHome Web.
    3. 
                                
  3. Füge den generierten YAML-Code ein.
    4. 
                                
  4. Klicke auf Install (per USB oder Wireless).
    5. 
                            

                        


                        
                        

                            
🌐 Methode 2: web.esphome.io (Browser)

                            
Direkt im Browser ohne Installation:

                            
    
                                
  1. Öffne web.esphome.io im Chrome/Edge Browser.
    2. 
                                
  2. Schließe den ESP per USB an und klicke auf Connect.
    3. 
                                
  3. Flashe die Basis-Firmware und verbinde das WLAN.
    4. 
                                
  4. Danach lädst du die erstellte YAML über OTA hoch.
    5. 
                            

                        


                        
                        

                            
💻 Methode 3: ESPHome CLI (Terminal)

                            
Für Entwickler und Terminal-Nutzer:

                            

                                esphome run <datei>.yaml
                            

                            
Kompiliert und flasht die Konfigurationsdatei vollautomatisch über USB oder OTA.
